# 🎬 Projectium

> A full-stack movie discovery application built with **Jetpack Compose** and **Golang**, powered by the **TMDB API**.

> 🚧 **Status:** Planning & Initial Development

---

## 📖 About

Projectium is a modern Android application created as a learning project to explore full-stack mobile development.

The application will allow users to browse popular movies, search titles, view detailed movie information, and maintain a personal watchlist while following modern software architecture and development practices.

---

## 🎯 Objectives

- Learn Jetpack Compose
- Learn Go backend development using Gin
- Design and consume REST APIs
- Implement Clean Architecture & MVVM
- Work with MongoDB and Room Database
- Build a complete portfolio-ready application

---
